## 0. 总纲（北极星，压倒一切）
- **判断标准是用户体验**——你跑着觉得她"真不真、假不假"，**不是测试几个绿、不是工程多严谨**。
- **防伪边界留着是因为它是体验**：她为讨好你随口编、再被固化成身份——那种"假"你一眼能感觉到。零伪造 = 她感觉是真的。
- **砍到最小**：你感觉不到的基建（provenance 审计、精确游标、回放系统）够用别崩即可，**绝不变成目的**。
- **单用户**：只有你一个人用。没有跨用户串台问题——关系就是**一段**（她↔你），可以简单处理。
- **验收 = 你跑着觉得对味**。能跑、你能感觉、不假，就往前。

> 路线翻案：留空 system.txt 背景是**故意**的——要她**自己活出来的人生，不是写的故事**。
> 所以不写背景；让她**活过的、落账的经历**结晶成持久、自洽的自己。深度轴（历史/关系/涌现/留白/一致），不是堆物品。

## 1. 种子（唯一预设，存进**世界引擎**不存聊天 prompt）
**种子是来源链最底层、不可变的基石，根扎世界引擎，聊天彻底当读者。**
- **存哪**：新建 `prompts/seed.json`，**不进 DB**。理由：① 不可变是种子的命，运行时从不写文件 → 物理免疫污染；
  ② 它是"预设"不是"状态"，不该塞每拍都改的 `WorldState`，也不该塞会演变的 `long_term_memory(subject="neno")`；
  ③ 跟现成 `SYSTEM_PROMPT = load_text(...)` 一致，加 `NENO_SEED = load_json("prompts/seed.json")` 零新机制；
  ④ "世界引擎拥有种子" = 只有它把种子当根读进 self_context，不靠物理位置靠来源链。
- **内容（4 项）**：`name=Neno` / `age=18` / `temperament`（偏活泼、暖、松弛随性、跟相处慢慢放开，**轻倾向不写死**）/
  `background_principle`（专业/学校/家乡/过去不是预设的，是真实生活长出来的；按已确立的自己来、和过去一致；没确立的自然带过，别现编固定设定）。
- **system.txt 砍成纯声音壳**（静态、可缓存）：只留"你叫 Neno；动态区「此刻的你」会告诉你你是谁/在哪/心情/跟对方处到哪——
  第一人称入戏说、别跳戏"。**事实一条不写**——事实从种子+世界经 self_context 流过来。背景整段删。

## 2. 中心不变量：防伪边界（这一刀的命，钉死）
**她的自我，只能从"正式 WorldLoop 里真发生、落账了的经历"里长——聊天能表达，不能创造。**

**来源链（放宽，不只 world_ops）**：
```
WorldLoop 正式推进
├─ LLM/routine 动作：action_validator → apply_op
├─ 自然漂移 / 睡醒(DayCycle) / 生活事件(LifeEventSource) / 滑行 等正式状态迁移
└─ episode / experience 记录
→ 持久化落账(life_world_state / 各 log 表)
→ reflection
→ long_term_memory(subject="neno")
```
核心条件 = **"由正式 WorldLoop 产生并落账"**，不是"必须过 apply_op"。

**硬不变量**：进 prompt 的"她是谁"只来自三类——① 种子 ② 已落账世界状态 ③ 有世界事件依据的自我事实。
**任何模型临时编、世界里没发生的背景/经历/身份，绝不在后续 prompt 复用。**

**做过 ≠ 身份（防止"推断式伪造"）**：自我事实分两类——
- **直接事实**：世界里明确发生过的（她今天去画了画）。
- **归纳事实**：多次经历形成的偏好/习惯/倾向（她**爱画画**、画画成了习惯）。
- **身份/传记类**（专业、学校、家乡、家庭、过去）**必须有世界里明确的对应事件**才成立，否则**保持未知**。
  → 反复画画只能结晶"画画是她的稳定偏好"，**推不出"她是设计专业"**。

**防伪靠"写入路径"保证，不靠存审计**：只有"反思落账事件"这条路能写 subject="neno"；聊天写不了。
所以 provenance 存储**第一刀不做**——哪天调试查不出某条事实哪来的，再给 `long_term_memory` 加 `source_json`。

## 3. 机制 A：自我库（自我事实结晶）
- **存哪**：复用 `long_term_memory`，`subject="neno"`。
- **只从落账经历来**：reflection 把已发生、已落库的经历结晶成自我事实（直接/归纳两类，身份类需明确事件）。
  聊天**不单独创设事实**——最多识别"她对既有世界事实的表达/引用"，找不到世界依据就不写。
- **普通经历不进自我库（防流水账，#7）**：「她今天去画画」这种留在 event/episode 里。
  只有**有持续身份意义、长期影响、或明确承诺**的直接事实才进 `long_term_memory(subject="neno")`；
  重复行为归纳成偏好/习惯（"爱画画"），但**不许推断成制度性身份**（"设计专业"）。
- **不可逆的是经历历史，不是当前属性**：旧事件不可删改（她曾长期画画=历史）；当前自我可演变（她现在不画了=可成立）；
  但不许否认旧事件（"她从没画过"=禁止）。

## 4. 机制 B：self_context（活的自我语境，全局·只读派生）
世界引擎维护一段"她当下是谁 + 在干嘛 + 跟你处到什么程度"，廉价 LLM 在变化够大时重写，聊天/world_brain 只读。
- **单用户 → 关系并回 self_context**：就一段关系，不用拆成 per-session 注入。self_context 涵盖"她自己 + 她跟你的亲密度"。
- **只读派生，绝不反向写回自我库**（堵循环污染：LLM 写摘要→world_brain 信→行动→反思把摘要证成事实）。
  唯一方向：**已落账世界事实 → self_context → 决策参考**。
- **合法输入来源（钉死，#5）**：组写**只能读**——**0 号输入 = 种子(`prompts/seed.json`，最底、最高优先)**
  ① 已持久化世界状态(life_world_state) ② 已持久化内在状态(agent_state 的精力/情绪)
  ③ 已持久化关系状态(relationship_state) ④ 有落账经历依据的自我事实(subject="neno")。
  **关系和情绪是合法来源，明确算进来**，不算违规。来源链一句话：**种子 + 已持久化真实状态与经历 → self_context**（不是"凭空摘要"）。
- **组写契约（防扩写，#6 软层）**：组写模型**只能压缩/转述输入里明确有的信息**；不得补专业/学历/家乡/家庭/过去等未提供事实；
  信息不足就省略，**不许合理推测**。→ 喂"经常画画"，输出不能冒出"设计专业学生"。
- **最小反扩写守门器（#6 硬层，让"绝不扩写"是真的）**：光靠 prompt 指令保不住，加一道便宜的码层守门：
  1. 组写前给输入事实**编号**，要求模型只基于编号事实组写；
  2. 对输出做**高风险传记词检测**（专业/学校/家乡/家庭/职业/过去 等身份锚）；
  3. 输出里出现**输入中没有的**高风险身份 → **拒绝本次结果、保留旧 self_context、记 warning、不阻断 WorldLoop**；
  4. 不做复杂审计——就一个关键词 guard，够堵"画画→设计专业"这类漂白即可。
- **何时重写（双层门控：显著变化 AND 最短间隔，#2）**：
  - **显著变化**才有资格触发：换房间 / 心情跨档 / 新自我事实。
  - **普通动作变化**只**累积**，不单独触发（否则 8 秒一 tick 会几秒重写一次、self_context 自抖）。
  - **最短间隔**：距上次生成 < `MIN_INTERVAL`（默认 ~600s）一律不重写；**最长**：数小时没更新可强制重组一次。
  - 不上正式游标；以后真要省再钉 `MAX(inner_experience_log.id)`。延迟不敏感、成本慢慢聊，但**间隔闸必须有**。
- **basis 必须落库（#1）**：`life_world_state` 新增 `self_context` / `self_context_basis` / `self_context_updated_at`。
  basis 至少存 `location / action / mood_band / relationship_revision / generated_at`——
  没它，重启后判断不了"变没变"，"失败不推进基准"就是空头支票。
- **独立 LLM 开关（#3）**：self_context 组写既不是 WorldBrain 决策也不是 DailyPlanner，**不复用世界 LLM 开关**：
  `CONSCIOUSNESS_SELF_CONTEXT_LLM_ENABLED=false`(示例默认关) / `CONSCIOUSNESS_SELF_CONTEXT_MIN_INTERVAL=600` /
  `OPENROUTER_SELF_CONTEXT_MODEL=openai/gpt-4o-mini`。关掉世界决策时 self_context 仍可单独开/关。
- **失败降级**：组写失败 → 留上一版、不推进 basis、不清空、记 trace_id、不阻断 WorldLoop，下次再试。
- **谁读（别整体替换 self_state_context.py，#4）**：`build_self_state_context()` 现在不只手拼生活状态，还管
  **睡眠表达 / `WORLD_PRESENCE_GATE_ENABLED` 在场门 / `DEFER_MARKER`「她可暂不回」/ 读失败降级**。
  **只把"手拼地点/动作/情绪/牵挂"那段换成读持久化的 self_context**，presence gate 和 DEFER_MARKER **原样保留**；
  必要时拆成两个动态上下文块，**装配位置不变**（现有动态槽位够用，不重设计 prompt 接口）。world_brain 也注入 self_context。

## 5. 关系：化掉 stage 离散阶梯（先换呈现，别删模型）
`prompts/stages/stage_0..4.txt` 是 5 个写死的亲密度档——正是要逃的脚本。
- **关系状态数据 + 更新机制保留**（relationship 那套，relationship.py）。**先只换"呈现"**：把固定 5 张 stage prompt
  换成由 LLM 连续生成的关系语境（并进 self_context），她对你**渐渐放开、连续**，不跳档。
- 关系也从**真实互动历史**长（守防伪边界，不凭空摘要）。
- 稳定后再决定要不要删 stage 字段/API（第一刀不删，避免牵动 schema/调试页/集成测试）。

## 6. 聊天的愿望/意图（现在定义，后面实现）
聊天的"我想学画画"是**意图候选**，不是事实。聊天**不直接写自我库、不直接改 life_world_state**；
只产意图候选，交世界引擎决定要不要吸收执行；真做了、落账了，才可能结晶。
**注意**：现有 `pending_messages` 是"睡着/暂不回时留消息"，**不是**通用"用户消息→世界事件"队列——别混用。
后续单独建正式 external event/意图入口（复用 session 串行化的必要元数据）。**第一刀只定义。**

## 9. 红线 / 原则
- **防伪边界是命**：进 prompt 的自我信息只来自 种子 / 已持久化真实状态(世界+内在+关系) / 有落账依据的自我事实；身份类需明确世界事件。
- self_context 只读、绝不写回自我库；组写不许扩写，且**有码层守门器**兜底(高风险传记词)。经历历史不可逆，当前自我可演变。
- **动聊天 prompt 是缓存敏感区**（被咬过）：受控迁移——旧契约→新契约→补缓存/顺序测试→替换，不顺手改；动态内容放历史后。
- 廉价 LLM gpt-4o-mini；示例配置默认关；不碰 .env；不 commit（用户亲自）。
- 基建（provenance/精确游标/回放）**第一刀不做，要了再增量长**。

## 10. 验收（体验为主）
**主**：你跑几天，觉得她**真、不假、连续**——不再每次现编专业、聊天里的她和世界里的她是同一个、跟你相处会自然放开。
**底线（够用即可，不做满审计）**：
- 进 prompt 的自我信息都能落到 种子/已落账经历（抽查看得出）。
- 聊天临时表达没直接写进自我库。
- **反扩写测试**：喂 self_context 组写模型只给"经常画画"，输出不出现"设计专业"等没给的传记信息；
  即便模型硬冒出来，**守门器拒绝该次结果、保留旧版**（断言旧 self_context 没被高风险词污染）。
- 行为没被自动推断成身份（爱画画 ≠ 设计专业）。
- self_context 没反向写回事实；旧事件没被新摘要抹掉。
