# Neno 多层思考与「真人感」重构 · 设计

> 状态：已被 `2026-07-10-unified-executive-multilayer-thinking-design.md` 取代；不要按本文旧权限图继续实现。
> 来源：2026-06 与用户的设计对话 + 对开源同类 `Shikigami-Lab/Shikigami-Protocol` 的调研。
> 配套必读：`NENO.md` §4（缓存契约红线）、`docs/living-world.md`。

## 1. 背景与问题

聊天侧为追求"真人感"叠了多层机制（`selection_layer` / `self_state_context` / `voice_self` / `fragmenter`），结果反而更像 AI。实测三个症状：

- **音量不随输入收缩**：对零信息输入（如「嗯嗯」）也用力回三拍 + 反问。
- **报数据**：把世界状态（`self_state_context` 注入的"在阳台/要去便利店"）当话题倒出来。`system.txt:11` 明禁却压不住。
- **AI 腔**：要么"贴心助手"腔，要么"半成品万岁"式接地气 cosplay（偏土/偏老/电视腔）。

**根因**：真人感被当成"可指令、可表演"的东西去**堆**。但真人感来自 **厚底子 + 狠克制 + 拆掉让她表演的脚手架**。

## 2. 目标 / 非目标

**目标**
- 出口随输入收缩：废话秒回或不回；走心的才走心。
- 结构上杜绝"报数据"。
- 风格不像 AI（既非助手腔，也非 cosplay 腔）。

**非目标（本设计不碰）**
- 不破坏 `context_builder` 缓存前缀顺序（`NENO.md` §4）。
- 不绕 `action_validator`、不破坏 Session 串行。
- 不动 living world 世界引擎本体。

## 3. 核心原则

1. **厚底子、薄出口**：状态/记忆/世界尽管堆，但堆在「状态」和「内心」，不堆在每句话。
2. **减法即真人**：多数思考层负责"毙掉"，不是"加料"。
3. **零形容词、靠具体棱角**：声音不靠"稳/随和"这类词，靠**具体口头禅 + 对比式定义（说 X 不说 Y）+ 明确禁令 + 字数**。（借鉴 Shikigami 人设文件写法。）
4. **防泄漏**：内心/世界状态最多喂到抑制层；出口层**物理上看不到**原始内心和世界状态。
5. **内容驱动，非时间/数量驱动**：先有"值得说的东西"才说（借 Shikigami 的 `speak_reason`/`urgency`）。

## 4. 架构：变深漏斗（被动回复 · 醒着路径）

物理睡眠门（presence）仍是最前的硬底。

```
用户消息（一波）
  │
① TRIAGE 分流〔廉价 MiMo；由 selection_layer 改造〕
  出: depth ∈ {不回, 浅, 深} + 情绪读数
  ├─ 不回 → 攒 pending（复用现有）
  ├─ 浅  → 轻量出口（跳内心/抑制）
  └─ 深 ↓
② 内心层〔深路才跑；廉价并行〕
  2a 并行涌念：N 股独立冲动同时跑（默认 3：暖 / 累·防备 / 联想）
  2b 打架汇流：谁占上风、谁被压、★残留拉扯（矛盾不强行调和）★
  → 永不外露、不进 messages 表、不进出口 prompt
③ 抑制层  出: { 说不说, 最多几条 }   ★零形容词★
④ 出口层  入: 抑制裁定 + voice_self 样本（拿不到原始内心/世界状态）
⑤ 回环·咽回  草稿过一道自我复看：可改 / 截 / 毙。★最多 1 次★
```

## 5. 层间接口（数据形状）

```
triage   → { depth: 不回|浅|深, emotion:{hit,tone,intensity} }
涌念(每股) → { drive, reaction(私有文本), pull: 0~1 }
汇流     → { dominant, suppressed[], felt, tension }
抑制     → { speak: bool, max_beats: int }          ← 不含任何口吻形容词
出口      → 草稿文本
回环     → { action: keep|revise|kill, final }
```

★ **出口层入参只有**：抑制裁定（说几条）+ 一个中性的"回应要点选择" + `voice_self` 真实样本 + 对话历史。**无口吻形容词、无原始世界状态** → 结构上无法报数据。

## 6. 声音来源（最难，部分待定）

- **种子绝不用她过去的 AI 回复**（那正是要逃的 slop，自长只会越练越 AI）。
- **用真人字**：用户自己的消息（库里现成、当下口气）+ 用户随手挑的几十条"对味"的真人话（剧/小说/主播/朋友聊天）。
- **用户只"按例子挑 / 贴"，不写形容词描述**（无抽象可写错，规避"写崩"）。
- **写法借 Shikigami 人设文件**：具体口头禅、对比定义、禁令（禁密集感叹号 / 禁每句动作 beat / 禁过度热心）、字数区间、state-dependent 长度（累了/深夜更短）。

> ⚠️ **开放风险（未解）**：用户目前**无现成真人语料**，且对亲手写有顾虑。**声音种子的获取是本设计最大未解风险**。落地需先**小规模试**（生成候选 → 用户挑"像/假"）验证可行，再扩；不可假设语料已就绪。

## 7. 借鉴 Shikigami 的三招（已读其源码验证）

1. **urgency 内容驱动 + `speak_reason`**：先找到值得说的，没由头 → 沉默。`urgency` 反映动机强度而非沉默时长。直接用在 triage/抑制，治"为发而发/报数据"。
2. **segment 注册表重构 `context_builder`**：每块上下文做成带 `priority / trigger / inject_into` 的段，各层（triage/内心/抑制/出口）取各自段集、公共段复用。**但动态段落点必须守在历史之后**（缓存红线，与 Shikigami 的"动态进 system 块"做法相反——它面向本地模型、无缓存经济学约束）。
3. **情绪升级为 3 层加权 blend**（替代单 `mood`），并防"情绪→能量→prompt"正反馈环（正向冲击压小，负向可大）。

## 8. 降级铁律（每层 fail-open）

| 层崩 | 行为 |
|---|---|
| triage | 退回"正常回"（≈现状），绝不默认沉默 |
| 涌念某股 | 少一股照常汇流；全崩 → 跳出口用现有兜底回 |
| 抑制 | 默认"说"、不毙杀（绝不因它崩而沉默） |
| 出口 | 退回现有 `generate_chat_reply` |
| 回环 | 草稿原样发 |

**总铁律**：任何层崩 → 退回"当前正常回复行为"，绝不卡死、绝不无故沉默（`NENO.md` §7）。

## 9. 成本 / 延迟

- **浅 / 不回**：1 次廉价（~1.3s）。**绝大多数消息。**
- **深**：triage + 3 并行廉价(≈1 次延迟) + 汇流 + 抑制 + 出口(主模型) + ≤1 回环 ≈ 几秒。**仅走心消息。** triage 门控把成本卡死。

## 10. 与现有层映射（重排，不堆新）

| 现有 | 去向 |
|---|---|
| `selection_layer` | → ① triage |
| `self_state_context` | → 只喂 ② 内心层（**不再灌出口**，根治报数据） |
| `voice_self` | → ④ 出口层口吻 |
| `fragmenter` | → 反应链路弃用（出口自然短） |

## 11. 实现分阶段（设计完整，落地分刀，每刀可验收）

- **刀 1**：triage 升级（depth/silence）+ 砍 `self_state_context` 短接（改喂内心）。最小验证"对嗯嗯克制 + 不报数据"。
- **刀 2**：内心层（并行涌念 + 汇流）+ 抑制层（零形容词接口）。
- **刀 3**：出口层 + 回环咽回 + **声音种子试验**（生成候选 → 用户挑）。
- **刀 4（可选）**：segment 注册表重构 `context_builder`；情绪 blend。

各刀守缓存 / 串行 / `action_validator` 红线；TDD；`nereboot` 起后端实测。

## 12. 验收

- **行为**：对「嗯嗯」回「嗯」或不回；不主动报生活状态；走心消息才多拍走心。
- **风格**：用户盲测"像不像人"——**唯一真验收，靠连续跑数日体感**，不是单测能判的。
