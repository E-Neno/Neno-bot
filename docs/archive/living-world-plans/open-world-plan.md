# 第 4 章：开放世界（Open World）— 计划

> 路线图第 4 步。前三步已完成：控制台 ✅ / 完善世界引擎 ✅（P0 墙钟作息 + 消息进世界经历流 +
> 没回变牵挂 + 世界 LLM 涌现日常）/ Phase 5 在场模型 ④ ✅。
>
> **目标**：她的世界不再是封闭的四房间循环——她成为一个**有过去的具体的人**，活在一个**更丰富、
> 可扩展、能走出去**的世界里。延续既定原则：LLM 在回路里临场决定（不堆规则表）、加法不改乘法、
> 复用现成机件（world_def / world_brain / life_events / experience / 牵挂）、红线友好。

## 现状（开工前必知）
- 世界 = 固定四房间公寓（`load_world_def()` 数据驱动：bedroom/kitchen/living_room/balcony + 固定物品）。
- 她已能：按精力涌现作息、世界 LLM 决定日常动作（带 world_ops 改世界）、攒牵挂、把你的消息记成经历。
- 世界 LLM / 日计划 LLM 已开（`.env` 本地配置，≈¥0.6/天）。

## 切法（按优先级，逐刀做 + 验）

### 刀 1：给她一个「过去」（底子）— 小、高价值、先做
之前推迟到本章的那件事。让她不再每次现编背景。
- **钉死人设**：在 `prompts/system.txt`（或独立设定）固定 专业 / 学校 / 家乡 / 几个固定习惯 /
  在意的东西。**和用户共创**——她是用户的，不是 AI 编的。
- **种初始记忆**：往长期记忆塞几条她的成形往事（`MemoryRecall.add_memory` 现成），让她开口
  就有历史。
- **种 1-2 个开机牵挂**：`open_threads` 里放一个未竟/余波，开机就有内心活动。
- 边界：只加「她是谁」的底子，不改决策机制。

### 刀 2：世界深度 — 中
给她的脑子更多可活的东西（现在四房间太空，动作翻来覆去）。
- 扩 `world_def`：现有房间加更多物品 / 物品状态（更丰富的交互）。
- 扩 `life_events`：更多事件种类（不止 weather/mishap/craving/memory）。
- 注意：world LLM 开着才有意义（mock 模式扩房间只是更长的死循环）。salience 表要覆盖新 kind。
- 边界：数据驱动为主，复用 world_brain；不复制第二套循环。

### 刀 3：出门 / 外部场所 — 大（本章核心「开放」）
让她能**走出公寓**。
- `world_def` 加外部场所（小区 / 街道 / 常去的店 / 咖啡馆…）+ 可达性。
- 「出门」作为一种活动 + 「在外面」的状态；world_brain 能决定出门、在外面做什么。
- 外部带来变量（遇到事、买东西、看到风景）→ 喂回经历流 / 事件 / 牵挂。
- 边界：先做「她能去几个固定外部点并带回经历」，别一上来造整座城。

### 刀 4（远期）：其他人 / NPC
她世界里除了用户之外的人（邻居、朋友、店员…）。大，单独评估，本章可不做。

## 风险/原则（沿用今晚的结论）
- **加法不改乘法**：新东西都是「读现成系统」，不引入紧耦合反馈回路（别再造 salience/阈值地狱）。
- **LLM 在回路里做判断**，不堆 if-else 规则表（这是「活」的来源）。
- **红线**：不绕 `action_validator`、不复制生产循环、世界 LLM/计划 LLM 示例配置默认关。
- 每刀：先验收脚本/单测 + 一次性验，再下一刀（参考今晚节奏）。

## 建议起点
**刀 1（给她一个过去）**——小、和用户共创、立刻让她更像一个连续的人。捋清「Neno 到底是谁」
再动手（用户起头，AI 补成连贯设定）。
