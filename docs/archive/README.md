# Archived Project Notes

这些文件保留历史背景，但不再作为当前实现或操作流程的真相源。当前开发入口仍以根目录 `README.md`、`NENO.md`、`NENO_ARCHITECTURE.md` 以及 `docs/living-world.md` 为准。

## Contents

| 目录 | 内容 |
| --- | --- |
| `root-history/` | 旧代码库分析、主动消息考古记录等根目录历史材料 |
| `living-world-plans/` | Living World 早期方案、开放世界 brief、未落地设计稿 |
| `world-view/` | 控制台视觉重设计、世界视图原型、Phaser 方案和 HTML 样张 |
| `integration-history/` | OpenClaw / 微信图片链路的历史审计和本地补丁记录 |
| `superpowers-plans/` | 已执行或已废弃的 superpowers 实施计划 |

## Rules

- 新代码或新文档不要引用这里作为当前行为依据。
- 需要恢复历史上下文时，可以阅读对应归档文件，再回到当前权威文档核对实现状态。
- 如果归档内容重新变成可执行计划，应移回 `docs/` 顶层并更新 README 文档表。
